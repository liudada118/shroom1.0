# 传感器协议与线序文档

每个传感器类型一份文档，文件名就是后端的类型名。内容是协议（波特率、帧头、帧长度、数据类型）和线序（原始数据怎么排成矩阵）。

- 本目录由脚本按后端代码生成：线序用后端实际的处理函数算出，并用随机数据逐点核对。没有在真实设备上核对。
- 「系统列表名称」为空的是旧类型：当前系统列表里没有，后端仍保留处理代码。
- 后端按帧长度分发数据，不看类型：任何类型的主通道收到 72、144、256 字节的帧都按接收顺序直接输出；收到 262 字节的帧按手套帧处理（256 点压力 + 6 字节姿态）。这些没有单独成文。
