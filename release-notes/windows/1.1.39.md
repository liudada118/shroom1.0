# Shroom 1.1.39

发布日期：2026-10-26

## 安装修复

- 安装前检查磁盘可用空间。空间不足时显示原因并停止，不再先卸载旧版后才发现新版本无法写入。
- 移除强制安装到 `D:\Shroom` 的设置，保留已有安装位置，首次安装使用系统默认位置；手动安装仍可选择其他目录。
- 修复安装到系统程序目录后，普通用户因无法创建导出目录而不能启动的问题。Windows的CSV和报告导出目录改为用户数据目录，旧导出文件保留原处。
- 本版保留1.1.38的小床默认俯视、X轴正反旋转、纯点图显示和应用工具悬停横幅。

## 已发生安装失败时

- 先完全退出Shroom，再手动运行本版完整安装包。
- 如果D盘空间不足，请在安装位置选择C盘或其他空间充足的磁盘。
