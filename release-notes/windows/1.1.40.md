# Shroom 1.1.40

发布日期：2026-10-27

## 问题修复

- 修复有效期较长的密钥仍提示“一周内过期”的问题，到期提示现在按密钥的实际有效期显示。
- 修复人体全身系统连接串口后，热力图没有变化、左侧压力图表和统计始终为零的问题。
- 修复采集中退出后无法重新进入系统的问题。返回系统列表前会先停止采集、等待保存收尾，并保留保存异常的结果提示。
- 修复串口断开后采集计时仍继续的问题，断开时同步结束采集；重新进入监测页时也不再主动关闭串口。
- 采集中断提示现在可以关闭，相同的结束回执不会反复弹出。

## 界面优化

- 人体全身优化参数统一收进右侧“调节”面板，减少画面重叠。
- 移除右下角内嵌的“2D 数字·全身”，部位视角移至该区域并避开工具栏。

## 安装说明

- 安装前请先结束采集并完全退出 Shroom，安装完成后重新启动应用。
- 本版包含前台和后台修复，需要更新完整 Windows 安装包。
