# Shroom 1.1.47

版本说明日期：2026-11-06

## 界面优化

- 监测页面的左右面板根据窗口宽度调整，改善中等尺寸窗口下图表、设置和点图相互遮挡的问题。
- 小床默认点图适配中间可用空间；隐藏图表或收起工具后，点图显示区域同步调整，并保留已保存的视角和缩放。
- 小床生命体征卡片更加紧凑，减少呼吸、心率区域的留白，让床状态和告警信息更容易查看。
- 算法超市根据窗口大小调整宽高，内容可在弹框内滚动，方便在较小窗口中操作。
- 改善中、英、日文界面在中等尺寸窗口中的按钮排布。

## 问题修复

- 修复数据回放完整播放一次后，再次点击播放按钮无响应的问题。播放结束后再次点击，会从当前选区起点重新播放；普通暂停后继续播放仍保留当前位置和倍速。
- 修复回放自然结束后，播放按钮和进度状态未及时同步的问题。

## 版本衔接

- 包含 1.1.46 的更新服务器迁移，后续更新继续通过新的软件下载地址获取。
- 本次为 Windows 安装包，回放修复同时包含软件前端与本机后台更新。
