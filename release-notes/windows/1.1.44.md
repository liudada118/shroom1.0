# Shroom 1.1.44

版本说明日期：2026-10-30

## 显示与调节

- 视角旋转、镜头缩放及横纵向翻转按系统和显示模式保存，退出后再次进入可恢复设置。
- 颜色调节支持自定义最大值，方便查看不同量程的压力变化。
- 小床、手部及支持的规则点图增加可调边缘缓冲宽度，让外围平缓降到零，改善高斯处理后的边缘异常凸起。
- 修复点图边框与主体进出场动画不同步的问题，动画过程中调整边框宽度也能连贯衔接。

## 使用体验

- 已验证且仍有效的同一密钥，进入系统及退出后重进不再重复联网验证；系统权限检查继续保留。
- 已保存完成的采集结果提示自动收起，关闭后刷新或重进不再重复出现；保存中和保存失败仍明确提示。
- 回放记录显示本地日期时间，替代难以辨认的数字时间戳，查找记录更方便。

## 诊断改进

- 完善启动异常、采集结果及使用事件的记录，提升问题定位所需信息的完整性。
- 改进异常与使用事件的待上传记录处理，在应用设置中显示已识别的记录缺失情况。
