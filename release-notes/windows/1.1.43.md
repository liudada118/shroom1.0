# Shroom 1.1.43

发布日期：2026-10-28

## 问题修复

- 手部检测的“初始值”现在持续生效：收到的 ADC 总和小于设定值时，不显示压力起伏；达到阈值后正常显示。调低阈值或设为 0 后，当前画面立即更新。
- 修复调节参数退出后丢失、不同系统参数混用的问题。各系统按显示模式分别保存并恢复设置，包含点大小、速度和设为 0 的参数。

## 界面优化

- 小床检测（数据）点击“仅显示3D点图”后，隐藏所有按钮、右上角叉叉和鼠标指针，让展示画面更简洁。按 Esc 可恢复界面和鼠标，实时数据继续显示。
- 补齐常用监测、采集、回放、调节、Agent 和应用设置的中英日文案；切换语言时同步更新常用提示与日期格式。部分高级编辑器和分析报表仍保留原有文案。

## 安装说明

- 本版为完整 Windows 安装包，包含此前版本的修复。
- 安装前请先结束采集并完全退出 Shroom，安装完成后重新启动应用。
