# Shroom 1.1.49

版本说明日期：2026-11-17

## 监测流畅度

- 优化监测页面的卡顿：手部检测、触觉手套、高速矩阵、整椅等系统的画面计算提速，配置较低的电脑上显示更连贯。
- 数据没有变化时不再重复计算，降低处理器占用。
- 点图的平滑效果、颜色和高度与之前一致。
- 监测页面的面板改为不透明的深色底，不再使用毛玻璃效果。

## 数据处理

- 工具箱「数据处理」新增「旋转 90°」：3D 点图和原始数据都可以把画面顺时针旋转，转四次回到原位。
- 原始数据新增「水平翻转」「纵向翻转」，可以和旋转一起使用。
- 旋转和翻转只改变显示方向，不改变采集、存储、回放和导出的数据。
- 每个系统的每种显示方式各自记住方向，点「恢复视角」即可还原。
- 画面旋转或翻转后暂不提供框选分析；手套、足底、机器人分区等多块拼接的原始数据暂不支持旋转和翻转。

## 问题修复

- 修复触觉手套「3D 皮肤」在调节过颜色、大小或过滤之后，再次进入时页面报错变成空白的问题。
- 修复宇树 G1、松延 N2、零次方 H1 触觉上衣在调节过颜色、大小或过滤之后，进入系统时页面报错变成空白的问题。
- 修复触觉手套右手「热力地图」手指和手掌位置错乱的问题：之前右手按压的位置显示不对或不显示，现在与左手镜像对应，并与「2D 数字」的右手点位一致。

## 版本衔接

- 包含1.1.48的启动立即检查更新、发现新版本自动打开更新详情。
- 本次为Windows x64安装包，需通过完整安装包升级生效。
