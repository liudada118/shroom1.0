# Shroom 1.1.38

发布日期：2026-10-26

## 新增功能

- 小床数据监测新增“仅显示3D点图”，可隐藏图表和工具，仅保留点图及右上角关闭入口；按 Esc 可恢复原界面。
- 视角调节新增“X轴−30°”，与“X轴+30°”配合进行正反旋转。

## 界面优化

- 小床默认使用俯视视角，进入页面、恢复视角和刷新后均回到对应垫面的正上方。
- 右下角应用工具改为悬停滑出横幅，移开后自动收起；收起时保留“应用工具／悬停展开”提示，同时支持触屏点击和键盘操作。
- 移除视角调节中的Y轴旋转按钮，以及监测页右下角重复的竖排视角图标，让点图区域更简洁。

## 问题修复

- 修复小床旋转中心偏离点图、连续点击旋转按钮后方向异常的问题。
- 修复恢复视角后镜头继续漂移的问题，保持点图中心与默认俯视状态稳定。
- 修复应用工具横幅中反馈入口悬停时意外收起，以及弹窗切换后的焦点异常。
