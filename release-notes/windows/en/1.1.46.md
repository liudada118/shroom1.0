# Shroom 1.1.46

Release notes date: 2026-11-06

## Software updates

- Moved the address for future installer updates to the new software download server.
- Older versions can upgrade to this version through the original update channel. After installation, later versions are checked for and downloaded from the new address.
- The existing update notice, download progress, and install confirmation flow are unchanged.

## Version continuity

- Includes the device connection, collection and playback, split-packet glove, and interface improvements from 1.1.45.
- This migration does not change how software keys, device connections, or local collection records are used.
