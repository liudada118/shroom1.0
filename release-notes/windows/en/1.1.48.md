# Shroom 1.1.48

Release notes date: 2026-11-06

## Update experience

- The app now checks for installer updates as soon as it starts, with no 30-second wait. It still checks every 4 hours while running, and you can also check manually.
- When a new version is found, the update details open automatically, so you can read the release notes and select download right away.
- Fixed an update notice that could be missed when the check finished before the interface had loaded.
- After you close the dialog for a version, it does not pop up again during the same session. You can still reopen it from the update badge in the bottom-right corner.

## Version continuity

- Includes the compact small bed Vital Signs layout, the monitoring page and Algorithm library layout adjustments, and the fix for replaying after playback ends, all from 1.1.47.
- Later installers continue to use the new software download address.
- This release is a Windows x64 installer. The update check and notice fixes take effect only after upgrading with the full installer.
