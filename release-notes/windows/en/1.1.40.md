# Shroom 1.1.40

Release date: 2026-10-27

## Bug fixes

- Fixed keys with a long validity period still showing an “expires within a week” warning. The expiration notice now reflects the key's actual validity period.
- Fixed an issue where, after connecting the serial port in the Full Body system, the heatmap did not change and the pressure charts and statistics on the left stayed at zero.
- Fixed being unable to re-enter a system after leaving during a collection. Before returning to the system list, the app now stops the collection, waits for saving to finish, and keeps the notice if saving failed.
- Fixed the collection timer continuing after the serial port disconnected. The collection now ends when the port disconnects, and re-entering the monitoring page no longer closes the serial port.
- The collection-interrupted notice can now be dismissed, and the same completion receipt no longer pops up repeatedly.

## Interface improvements

- The Optimized Full Body parameters are now grouped in the “Adjust” panel on the right, reducing on-screen overlap.
- Removed the embedded “2D Data · Full Body” panel from the bottom-right corner. Body views moved into that area and no longer overlap the toolbar.

## Installation notes

- Before installing, end any collection and quit Shroom completely. Restart the app after installation finishes.
- This version includes both front-end and back-end fixes, so the full Windows installer is required.
