# Shroom 1.1.38

Release date: 2026-10-26

## New features

- Small bed data monitoring adds “Show only 3D points”, which hides charts and tools and keeps only the point view and the close button in the top-right corner. Press Esc to restore the full interface.
- View adds “X axis −30°”, which pairs with “X axis +30°” to rotate in both directions.

## Interface improvements

- The small bed now defaults to a top-down view. Opening the page, resetting the view, and refreshing all return to directly above the mat.
- App tools in the bottom-right corner is now a banner that slides out on hover and collapses when the pointer leaves. While collapsed it keeps the “App tools / Hover to expand” hint, and it also supports touch and keyboard use.
- Removed the Y-axis rotation button from View, along with the duplicate vertical view icons in the bottom-right corner of the monitoring page, for a cleaner point view area.

## Bug fixes

- Fixed the small bed rotating around a point off the point view, and the direction going wrong after selecting the rotate button repeatedly.
- Fixed the camera continuing to drift after resetting the view. The point view center and the default top-down view now stay stable.
- Fixed the App tools banner collapsing unexpectedly when hovering over the feedback entry, and incorrect focus after switching dialogs.
