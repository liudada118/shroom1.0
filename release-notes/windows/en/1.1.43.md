# Shroom 1.1.43

Release date: 2026-10-28

## Bug fixes

- The Hand Detection “Initial Value” now applies continuously: while the received ADC total is below the set value, no pressure changes are displayed; once it reaches the threshold, the display is normal. After you lower the threshold or set it to 0, the current view updates immediately.
- Fixed adjustment parameters being lost after exiting and being mixed up between systems. Each system now saves and restores its settings per display mode, including point size, speed, and parameters set to 0.

## Interface improvements

- In Small Bed Detection (Data), selecting “Show only 3D points” now hides all buttons, the close button in the top-right corner, and the mouse pointer, for a cleaner presentation. Press Esc to restore the interface and the pointer. Live data keeps updating throughout.
- Completed the Chinese, English, and Japanese text for common monitoring, collection, playback, adjustment, Agent, and App settings screens. Switching languages also updates common prompts and date formats. Some advanced editors and analysis reports still use their original text.

## Installation notes

- This is a full Windows installer and includes the fixes from earlier versions.
- Before installing, end any collection and quit Shroom completely. Restart the app after installation finishes.
