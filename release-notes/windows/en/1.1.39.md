# Shroom 1.1.39

Release date: 2026-10-26

## Installation fixes

- The installer now checks free disk space before installing. If there is not enough space, it shows the reason and stops, instead of uninstalling the old version first and only then finding that the new version cannot be written.
- Removed the setting that forced installation to `D:\Shroom`. An existing installation keeps its location, and a first-time installation uses the system default location. You can still choose another folder when installing manually.
- Fixed an issue where, after installing to the system program folder, standard users could not start the app because it could not create the export folder. On Windows, CSV and report exports now go to the user data folder. Existing export files stay where they are.
- This version keeps the small bed default top-down view, X-axis rotation in both directions, point-view-only display, and the App tools hover banner from 1.1.38.

## If an installation has already failed

- Quit Shroom completely, then run the full installer for this version manually.
- If drive D does not have enough space, choose drive C or another drive with enough space as the installation location.
