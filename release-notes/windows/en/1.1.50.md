# Shroom 1.1.50

Release notes date: 2026-11-19

## Software updates

- Installer updates now have a second download address: computers set to a mainland China time zone try the domestic address first, and all other time zones try the overseas address first.
- If the preferred address cannot be reached or its server returns a temporary error, the app checks the other address automatically. An update failure is shown only when both addresses are unavailable.
- Automatic address selection takes effect from this version. Upgrading to this version from 1.1.49 or earlier still uses the previous address.

## Small Bed Monitor

- The bed-exit voice alert now plays as soon as the bed state changes, instead of waiting for the algorithm's continuous in-bed duration. A short stay in bed is announced as well. The emergency alert rules are unchanged.
- The bed-edge voice alert likewise plays as soon as the bed state changes to sitting on the bed edge, instead of waiting for the algorithm's bed-edge alarm.
- “Total Pressure”, “Average Pressure”, “Peak Pressure”, and “Active Points” are now calculated from the sensor's original 32×32 points. “Active Points” is at most 1024 and no longer shows values of seven or eight thousand.
- After this change, “Average Pressure” reads higher than before, which is expected. The calculation of “Pressure Area” is unchanged.
- Fixed an error in the small bed systems when data arrived before the view had finished loading.

## Data export

- Fixed CSV export failing, or producing an empty file, when the collection name contained characters such as / \ : ? * " < > | or was too long. These characters are replaced with “-” in the file name.

## Version History

- “Version History” now supports English and Japanese: when the interface is set to English or Japanese, the release notes are shown in that language, and versions without a translation are shown in Chinese.

## Diagnostics

- When choosing a folder, loading history data, generating a report, or a similar operation fails, a more complete error reason is recorded to help locate the problem.

## Version continuity

- Includes the smoother monitoring, rotation and flipping, and the Tactile Gloves and Tactile Suit fixes from 1.1.49.
- This release is a Windows x64 installer and takes effect only after upgrading with the full installer.
