# Shroom 1.1.47

Release notes date: 2026-11-06

## Interface improvements

- The left and right panels on the monitoring page now adjust to the window width, reducing overlap between charts, settings, and the point view in medium-sized windows.
- The small bed default point view now fits the available space in the middle. When you hide charts or collapse tools, the point view area adjusts with them and keeps the saved view and zoom.
- The small bed Vital Signs cards are more compact, with less empty space around respiration and heart rate, making bed status and alerts easier to see.
- The Algorithm library now sizes its width and height to the window, and its content scrolls inside the dialog, making it easier to use in smaller windows.
- Improved button layout in medium-sized windows for the Chinese, English, and Japanese interfaces.

## Bug fixes

- Fixed the play button not responding after playback had played through once. Selecting play after playback ends now restarts from the beginning of the current selection. Resuming after a normal pause still keeps the current position and speed.
- Fixed the play button and progress state not updating promptly when playback ended on its own.

## Version continuity

- Includes the update server migration from 1.1.46. Later updates continue to come from the new software download address.
- This release is a Windows installer. The playback fix includes updates to both the app front end and the local back end.
