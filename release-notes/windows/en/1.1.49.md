# Shroom 1.1.49

Release notes date: 2026-11-17

## Monitoring smoothness

- Reduced stutter on the monitoring page: rendering calculations are faster for Hand Detection, Tactile Gloves, high-speed matrices, Full Chair, and similar systems, so the display is smoother on lower-spec computers.
- Calculations are no longer repeated when the data has not changed, lowering CPU usage.
- The smoothing, colors, and height of the point view are the same as before.
- Panels on the monitoring page now use an opaque dark background instead of the frosted-glass effect.

## Data processing

- “Processing” in the Toolbox adds “Rotate 90°”: both the 3D point view and Raw Data can be rotated clockwise, and four rotations return to the original orientation.
- Raw Data adds “Flip horizontally” and “Flip vertically”, which can be combined with rotation.
- Rotation and flipping change only the display orientation. They do not change collected, stored, played back, or exported data.
- Each display mode of each system remembers its own orientation. Select “Reset view” to restore it.
- Region analysis is not available while the view is rotated or flipped. Raw Data made up of several stitched blocks, such as gloves, insoles, and robot zones, does not support rotation or flipping yet.

## Bug fixes

- Fixed the Tactile Gloves “3D Skin” view showing an error and going blank on re-entry after color, size, or filter had been adjusted.
- Fixed the Unitree G1, Songyan N2, and LCF H1 Tactile Suits showing an error and going blank when entering the system after color, size, or filter had been adjusted.
- Fixed misplaced fingers and palm in the right-hand “Pressure Terrain” view for Tactile Gloves. Previously, presses on the right hand appeared in the wrong place or not at all. The right hand now mirrors the left hand and matches the right-hand points in “2D Data”.

## Version continuity

- Includes the immediate update check at startup and automatic opening of update details for a new version, both from 1.1.48.
- This release is a Windows x64 installer and takes effect only after upgrading with the full installer.
