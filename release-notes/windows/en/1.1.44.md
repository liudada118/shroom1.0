# Shroom 1.1.44

Release notes date: 2026-10-30

## Display and adjustment

- View rotation, camera zoom, and horizontal and vertical flips are saved per system and display mode, and are restored when you exit and come back.
- Color adjustment supports a custom maximum, making it easier to view pressure changes across different ranges.
- The small bed, hand, and supported regular point views add an adjustable edge buffer width, which lets the outer area fall smoothly to zero and reduces abnormal raised edges after Gaussian processing.
- Fixed the point view border and body being out of sync during enter and exit animations. Changing the border width during an animation now transitions smoothly too.

## Usability

- For the same key that has already been verified and is still valid, entering a system or exiting and re-entering no longer repeats online verification. System permission checks remain in place.
- Notices for collections that have finished saving now collapse automatically, and once closed they do not reappear after a refresh or re-entry. Saving-in-progress and save-failed states are still shown clearly.
- Playback records show the local date and time instead of hard-to-read numeric timestamps, making records easier to find.

## Diagnostics improvements

- Improved logging of startup errors, collection results, and usage events, so that the information needed to locate problems is more complete.
- Improved handling of error and usage-event records waiting to be uploaded. App settings now shows any record gaps that have been detected.
