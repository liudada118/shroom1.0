# Shroom 1.1.48

リリースノート作成日：2026-11-06

## アップデート体験

- アプリの起動直後にインストーラーの更新を確認するようになり、30 秒待つ必要がなくなりました。起動中はこれまでどおり 4 時間ごとに確認し、手動でも確認できます。
- 新しいバージョンが見つかると更新の詳細を自動的に開き、リリースノートを確認してそのままダウンロードできます。
- 画面の読み込みより先に確認結果が届いた場合に、更新のお知らせが表示されないことがある問題を修正しました。
- 同一バージョンのポップアップを閉じると、本セッション内では再表示されません。右下のアップデートアイコンから再度呼び出せます。

## バージョンの引き継ぎ

- 1.1.47 の小型ベッドのバイタルサインのコンパクトなレイアウト、モニタリング画面とアルゴリズムライブラリのレイアウト調整、再生終了後の再生し直しの修正を含みます。
- 以降のインストーラーも、新しいソフトウェアダウンロード先を引き続き使用します。
- 今回は Windows x64 インストーラーです。更新の確認とお知らせに関する修正は、完全版インストーラーでアップグレードすると有効になります。
