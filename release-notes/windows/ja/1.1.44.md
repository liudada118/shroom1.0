# Shroom 1.1.44

リリースノート作成日：2026-10-30

## 表示と調整

- 視点の回転、カメラのズーム、左右・上下の反転をシステムと表示モードごとに保存し、終了して入り直したときに復元します。
- 色の調整で最大値を任意に設定できるようになり、異なるレンジの圧力変化を確認しやすくなりました。
- 小型ベッド、手、および対応する規則的な点群表示に、調整可能なエッジバッファの幅を追加しました。外周を滑らかにゼロまで下げ、ガウス処理後に端が不自然に盛り上がる現象を改善します。
- 点群表示の枠と本体で、表示・非表示のアニメーションがずれる問題を修正しました。アニメーション中に枠の幅を変更しても滑らかにつながります。

## ユーザー体験

- 検証済みで有効な同一キーについては、システムへのログイン、ログアウト後の再ログイン時に再度ネットワーク検証を実施しない。システム権限チェックは継続して維持する。
- 保存完了済みの収集結果通知は自動的に折りたたむ。閉じた後にリフレッシュまたは再入室しても再表示されない。保存中および保存失敗の通知は明示的に表示する。
- 再生記録には判読しにくい数値タイムスタンプの代わりにローカル日時を表示し、記録の検索を容易にする。。

## 診断の改善

- 起動時の異常、収集結果、利用イベントの記録を強化し、問題の特定に必要な情報がそろいやすくなりました。
- 異常と利用イベントのアップロード待ち記録の扱いを改善し、検出された記録の欠落をアプリ設定に表示するようにしました。
