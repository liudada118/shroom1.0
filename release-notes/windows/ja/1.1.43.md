# Shroom 1.1.43

リリース日：2026-10-28

## 不具合の修正

- 手の検出の「初期値」が常に適用されるようになりました。受信した ADC の合計が設定値より小さい間は圧力の起伏を表示せず、しきい値に達すると通常どおり表示します。しきい値を下げるか 0 にすると、現在の画面にすぐ反映されます。
- 調整したパラメーターが終了後に失われる問題と、異なるシステムのパラメーターが混ざる問題を修正しました。各システムは表示モードごとに設定を保存・復元します。点のサイズ、速度、0 に設定したパラメーターも対象です。

## 画面の改善

- 小型ベッド検出（データ）で「3D 点表示のみ」を選ぶと、すべてのボタン、右上の閉じるボタン、マウスポインターを隠し、表示をよりすっきりさせます。Esc キーで画面とマウスポインターが元に戻ります。その間もリアルタイムデータは表示され続けます。
- よく使うモニタリング、収集、再生、調整、Agent、アプリ設定の文言を中国語・英語・日本語でそろえました。言語を切り替えると、よく使うメッセージと日付の形式も切り替わります。一部の高度なエディターと分析レポートは、従来の文言のままです。

## インストールについて

- 本バージョンは Windows の完全版インストーラーで、これまでのバージョンの修正を含みます。
- インストールの前に収集を終了し、Shroom を完全に終了してください。インストール完了後にアプリを再起動してください。
