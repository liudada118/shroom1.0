# Shroom 1.1.39

リリース日：2026-10-26

## インストールの修正

- インストール前にディスク空き容量を確認。容量不足時は原因を表示して停止し、旧版アンインストール後に新版書き込み失敗となることを回避します。
- インストール先を `D:\Shroom` に固定する設定を削除しました。既存のインストール先はそのまま引き継ぎ、初回インストールではシステムの既定の場所を使用します。手動でインストールする場合は、引き続き別のフォルダーを選べます。
- システムのプログラムフォルダーにインストールすると、標準ユーザーではエクスポート用フォルダーを作成できずに起動できない問題を修正しました。Windows では、CSV とレポートのエクスポート先をユーザーデータフォルダーに変更しました。以前のエクスポートファイルは元の場所に残ります。
- 本バージョンは、1.1.38 の小型ベッドの既定の真上からの視点、X 軸の両方向回転、点群のみの表示、アプリツールのホバーバナーを引き継いでいます。

## すでにインストールに失敗している場合

- Shroom を完全に終了してから、本バージョンの完全版インストーラーを手動で実行してください。
- D ドライブの空き容量が足りない場合は、インストール先に C ドライブなど空き容量が十分なドライブを選んでください。
