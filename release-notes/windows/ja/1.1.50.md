# Shroom 1.1.50

リリースノート作成日：2026-11-19

## ソフトウェアの更新

- インストーラー更新に予備のダウンロード先を追加しました。PC のタイムゾーンが中国本土の場合は国内のアドレスを、それ以外のタイムゾーンでは海外のアドレスを優先して使用します。
- 優先するアドレスに接続できない場合や、サーバーが一時的にエラーを返した場合は、もう一方のアドレスで自動的に再確認します。両方のアドレスが利用できない場合にのみ、更新の失敗を表示します。
- アドレスの自動選択はこのバージョンから有効になります。1.1.49 以前からこのバージョンへアップグレードする際は、従来のアドレスを使用します。

## 小型ベッドモニター

- 離床の音声通知を、ベッド状態が変わった時点で再生するようにしました。アルゴリズムの「連続在床時間」の判定を待たないため、少しの間だけ横になった場合も「離床しました」と通知します。緊急通報の規則は変わりません。
- 端座位の音声通知も、ベッド状態が端座位に変わった時点で再生するようにしました。アルゴリズムの端座位アラームを待ちません。
- 「総圧力」「平均圧力」「ピーク圧力」「有効点数」を、センサー本来の 32×32 点のデータから計算するように変更しました。「有効点数」は最大 1024 となり、七千や八千といった値は表示されなくなります。
- この変更により「平均圧力」の値はこれまでより大きくなりますが、正常な変化です。「受圧面積」の計算方法は変わりません。
- 小型ベッド系のシステムで、画面の読み込みが終わる前にデータを受信するとエラーになる問題を修正しました。

## データのエクスポート

- 収集名に / \ : ? * " < > | などの文字が含まれている場合や、名前が長すぎる場合に、CSV のエクスポートに失敗する、または空のファイルが出力される問題を修正しました。これらの文字はファイル名では「-」に置き換えられます。

## バージョン履歴

- 「バージョン履歴」が英語と日本語に対応しました。表示言語を英語または日本語に切り替えると、その言語のリリースノートを表示します。翻訳がないバージョンは中国語で表示します。

## 問題の診断

- フォルダーの選択、履歴データの読み込み、レポートの生成などの操作でエラーが発生した際に、より詳しいエラー原因を記録し、問題を特定しやすくしました。

## バージョンの引き継ぎ

- 1.1.49 のモニタリングのスムーズ化、回転と反転、および触覚手袋と触覚スーツの修正を含みます。
- 今回は Windows x64 インストーラーです。完全版インストーラーでアップグレードすると有効になります。
