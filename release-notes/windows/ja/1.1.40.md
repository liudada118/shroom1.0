# Shroom 1.1.40

リリース日：2026-10-27

## 不具合の修正

- 有効期間が長いキーでも「1 週間以内に期限切れ」と表示される問題を修正しました。期限のお知らせは、キーの実際の有効期間に基づいて表示されます。
- 全身システムでシリアルポートを接続した後、ヒートマップが変化せず、左側の圧力グラフと統計が常にゼロになる問題を修正しました。
- 収集中に終了すると、システムに入り直せなくなる問題を修正しました。システム一覧に戻る前に収集を停止して保存の完了を待ち、保存に失敗した場合はその結果を引き続き表示します。
- シリアルポートが切断された後も収集のタイマーが進み続ける問題を修正しました。切断と同時に収集を終了します。また、モニタリング画面に入り直したときにシリアルポートを閉じないようにしました。
- 収集中断のお知らせを閉じられるようにし、同じ終了通知が繰り返し表示されないようにしました。

## 画面の改善

- 全身（最適化）のパラメーターを右側の「調整」パネルにまとめ、画面の重なりを減らしました。
- 右下に埋め込まれていた「2Dデータ · 全身」を削除し、部位別視点をその場所に移してツールバーと重ならないようにしました。

## インストールについて

- インストールの前に収集を終了し、Shroom を完全に終了してください。インストール完了後にアプリを再起動してください。
- 本バージョンにはフロントエンドとバックエンドの両方の修正が含まれるため、Windows の完全版インストーラーでの更新が必要です。
