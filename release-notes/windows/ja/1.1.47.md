# Shroom 1.1.47

リリースノート作成日：2026-11-06

## 画面の改善

- モニタリング画面の左右のパネルがウィンドウの幅に合わせて調整されるようになり、中くらいのサイズのウィンドウでグラフ、設定、点群表示が重なり合う問題を改善しました。
- 小型ベッドの既定の点群表示を、中央の空きスペースに合わせるようにしました。グラフを隠したりツールを閉じたりすると点群表示の領域も合わせて調整され、保存済みの視点とズームは保たれます。
- 小型ベッドのバイタルサインのカードをよりコンパクトにし、呼吸と心拍数のまわりの余白を減らして、ベッドの状態とアラートを確認しやすくしました。
- アルゴリズムライブラリの幅と高さをウィンドウサイズに合わせて調整し、内容をダイアログ内でスクロールできるようにしました。小さめのウィンドウでも操作しやすくなります。
- 中国語・英語・日本語の画面で、中サイズのウィンドウでのボタンの並びを改善しました。

## 不具合の修正

- データの再生を最後まで 1 回行った後、再生ボタンをもう一度押しても反応しない問題を修正しました。再生終了後にもう一度押すと、現在の選択範囲の先頭から再生し直します。通常の一時停止から再開する場合は、これまでどおり現在の位置と再生速度を保ちます。
- 再生が自然に終了した後、再生ボタンと進行状況の表示がすぐに更新されない問題を修正しました。

## バージョンの引き継ぎ

- 1.1.46 の更新サーバーの移行を含みます。以降の更新も、新しいソフトウェアダウンロード先から取得します。
- 今回は Windows インストーラーパッケージとなり、再生に関する修正にはソフトウェアフロントエンドとローカルバックエンドの更新が含まれます。
