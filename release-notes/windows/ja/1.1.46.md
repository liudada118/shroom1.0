# Shroom 1.1.46

リリースノート作成日：2026-11-06

## ソフトウェアの更新

- 今後のインストーラー更新の配信元を、新しいソフトウェアダウンロードサーバーに移行しました。
- 旧バージョンは従来の更新経路から本バージョンにアップグレードできます。インストール後は、新しい配信元で以降のバージョンの確認とダウンロードを行います。
- 現在更新のお知らせ、ダウンロードの進行状況、インストール確認の流れはそのままです。

## バージョンの引き継ぎ

- 1.1.45 のデバイス接続、収集と再生、手袋の分割パケット、画面の改善を含みます。
- 今回の移行で、ソフトウェアのキー、デバイスの接続、ローカルの収集記録の使い方は変わりません。
