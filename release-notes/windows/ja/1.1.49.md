# Shroom 1.1.49

リリースノート作成日：2026-11-17

## モニタリングのスムーズさ

- モニタリング画面のカクつきを改善しました。手の検出、触覚手袋、高速マトリクス、椅子全体などのシステムで画面の計算を高速化し、性能が低めの PC でも表示がスムーズになります。
- データに変化がないときは再計算を行わず、CPU 使用率を下げました。
- 点群表示のスムージング、色、高さはこれまでと同じです。
- モニタリング画面のパネルを不透明な暗色の背景に変更し、すりガラス効果を廃止しました。

## データ処理

- ツールボックスの「データ処理」に「90° 回転」を追加しました。3D 点群表示と生データのどちらも画面を時計回りに回転でき、4 回で元の向きに戻ります。
- 生データに「左右反転」と「上下反転」を追加しました。回転と組み合わせて使えます。
- 回転と反転は表示の向きだけを変更します。収集、保存、再生、エクスポートされるデータは変わりません。
- システムごと、表示方式ごとに向きを記憶します。「視点をリセット」を押すと元に戻ります。
- 画面を回転または反転しているときは、範囲分析を利用できません。手袋、足底、ロボットの各部位など、複数のブロックをつなぎ合わせた生データは、現時点では回転と反転に対応していません。

## 不具合の修正

- 触覚手袋の「3Dスキン」で、色、サイズ、フィルターを調整した後に入り直すと、エラーが発生して画面が真っ白になる問題を修正しました。
- Unitree G1、Songyan N2、LCF H1 の触覚スーツで、色、サイズ、フィルターを調整した後にシステムに入ると、エラーが発生して画面が真っ白になる問題を修正しました。
- 触覚手袋の右手の「ヒートマップ」で、指と手のひらの位置がずれる問題を修正しました。これまでは右手で押した位置が正しく表示されない、または表示されないことがありましたが、左手と鏡像の関係で表示され、「2Dデータ」の右手の点の位置とも一致するようになりました。

## バージョンの引き継ぎ

- 1.1.48 の起動直後の更新確認と、新しいバージョンが見つかったときに更新の詳細を自動的に開くようにしました。
- 今回は Windows x64 インストーラーです。完全版インストーラーでアップグレードすると有効になります。
