# Shroom 1.1.48

版本说明日期：2026-11-06

## 更新体验

- 软件启动后立即检查安装包更新，无需再等待30秒；运行中仍每4小时检查一次，也可手动检查。
- 发现新版本后自动打开更新详情，直接查看版本说明并点击下载。
- 修复检查结果早于界面加载时可能漏掉更新提示的问题。
- 同一版本的弹窗关闭后，本次运行中不再反复弹出，仍可从右下角更新标记重新打开。

## 版本衔接

- 包含1.1.47的小床生命体征紧凑布局、监测页面和算法超市适配，以及回放结束后再次播放的修复。
- 后续安装包继续使用新的软件下载地址。
- 本次为Windows x64安装包，更新检查和提示修复需通过完整安装包升级生效。
