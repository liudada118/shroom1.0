# Shroom 1.1.45

版本说明日期：2026-11-03

## 设备连接

- 16×16 高速默认波特率调整为 921600，并修复分包手套接入后不显示数据的问题。
- 串口参数改为数字输入框，打开页面即可看到当前系统的默认波特率，可在连接前修改；旧版宿主也能显示默认数字。
- 优先按默认参数连接并读取数据，当前连接持续两秒无有效数据时再识别；识别出其他兼容波特率时，提示确认后连接。
- 正常连接、读取提示延迟两秒显示，减少快速连接时的提示闪现；真实错误仍及时提示。
- 改善手套分包数据的隔离，避免断开重连或切换系统后混入旧数据；采集及保存期间禁止修改串口连接。

## 回放与使用体验

- 修复从回放返回系统列表后，再次进入仍停留在回放状态的问题；重新进入默认显示实时模式。
- 修复 64×64 高速回放中异常短帧影响后续图形显示的问题，清屏与回放保持完整矩阵尺寸。
- 优化压力背心的调节与部位视角布局，统一全身传感的操作方式，并修正颜色按钮被拉伸的问题。
- 有新版本时，可直接点击更新提示查看详情；浏览系统列表时提前加载监测页面资源。
- 修复公司系统目录同步中的请求竞态，避免同步成功结果被旧状态覆盖。

## 交付验证

- 新增针对实际打包产物的自动验收，覆盖模拟设备连接、采集、保存、回放及数据导出。
- 增加小床 12B、手部、分包手套及高速矩阵等模拟场景；模拟验收不能代替实体硬件测试。
