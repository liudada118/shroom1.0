# Shroom 1.1.50

版本说明日期：2026-11-19

## 软件更新

- 安装包更新增加备用下载地址：电脑时区为中国大陆时优先访问国内地址，其他时区优先访问海外地址。
- 首选地址连接不上或服务器暂时出错时，自动改用另一个地址重新检查，两个地址都不可用才提示更新失败。
- 地址自动选择从本版本开始生效；1.1.49 及更早版本升级到本版本时仍使用原来的地址。

## 小床监测

- 离床语音改为床状态一变就播报，不再等算法判定「连续在床时长」：人只躺一会儿就起来也会有「已离床」提示。紧急求助的提示规则不变。
- 坐床边语音同样改为床状态一变成坐床边就播报，不再等算法给出坐床边报警。
- 「压力总和」「平均压力」「峰值压力」「有效点数」改为按传感器原始的 32×32 点阵计算，「有效点数」最多 1024，不再出现七八千的数值。
- 统计方式调整后，「平均压力」的数值会比之前大，属于正常变化；「受压面积」的算法不变。
- 修复小床类系统在画面还没有加载完成时收到数据会报错的问题。

## 数据导出

- 修复采集名称包含 / \ : ? * " < > | 等字符或名称过长时，导出 CSV 失败或导出的文件为空的问题；这些字符在文件名中替换为「-」。

## 版本历史

- 「版本历史」支持英文和日文：界面切换到英文或日文时显示对应语言的版本说明，没有译文的版本显示中文。

## 问题诊断

- 文件夹选择、历史数据加载、报告生成等操作出错时，记录更完整的错误原因，便于定位问题。

## 版本衔接

- 包含1.1.49的监测流畅度优化、旋转与翻转，以及触觉手套和触觉上衣的修复。
- 本次为Windows x64安装包，需通过完整安装包升级生效。
