# Shroom 本次版本更新销售公告

> 销售内部待发布稿，整理日期：2026-10-20。正式版本号与生效时间以发布通知为准；以下为本次交付范围，须在客户端、服务端部署和交付验收完成后通知客户。模型目录接口等最新改动目前仅完成源码实现。

## 公告正文

本次 Shroom 更新重点完善授权管理、AI 辅助分析和定制系统交付。请销售在开通、演示、报价及续费沟通时关注以下变化。

1. **开钥支持关联合同。** 将密钥与合同、客户信息关联，方便核对授权来源和交付记录。在线开钥入口增加合同确认及无合同申请流程，无合同场景按现有审批规则处理。

2. **支持按电脑台数授权。** 普通密钥默认不限量，限制密钥单独管理，可根据约定设置允许使用软件的电脑数量。超出名额的新电脑不能继续激活，需要增加名额或处理原电脑授权；同机正常升级不重复占用名额。

3. **内置 Agent 辅助使用和算法开发。** 客户可通过对话查询当前系统和设备状态、选择采集记录进行历史分析，并使用已标注数据训练分类算法。兼容的已保存算法可进一步绑定到系统进行实时展示；支持历史聊天、附件导入以及对话内选择数据。内置分类训练不要求客户配置显卡。

4. **定制展示系统可通过公司系统库交付。** 员工制作后提交审核，由超级管理员发布。客户凭包含对应系统权限的有效密钥获取系统，支持后续版本更新与回退。受支持的配置和算法包可以独立交付，减少重复制作完整安装包。

5. **兼容网页可独立更新。** 联网时后台检查并缓存兼容的新页面，下次启动启用；断网时继续使用本地可用页面。采集中不会因网页更新主动刷新。涉及设备驱动、原生组件或新的后台能力时，仍需升级完整软件。

6. **扩展设备展示，完善矩阵工具。** 增加压力背心展示，整合单双手触觉手套入口，并优化小床算法及床型配置。生成的矩阵系统统一图表和工具布局，支持相应视图切换、调节、框选及量尺；实际可用项目以具体系统和设备兼容清单为准。

7. **授权到期后的操作范围更明确。** 软件密钥正常到期后停止新连接和采集，保留已有记录，可继续查看历史、回放和使用 Agent 分析；软件内文件导出受限。请销售提前沟通续费，避免影响客户继续采集或导出。

8. **增强保存反馈和售后诊断。** 采集结束时更清楚地显示保存结果，补充实际运行版本、更新状态、使用统计及脱敏错误上报，便于定位问题。同机同账号正常升级保留既有聊天和采集数据；统计与错误上报可在设置中关闭。

## 销售开通前确认

请统一确认 **客户、合同或审批依据、授权系统、有效期、是否限电脑台数**。演示定制系统或新算法时，同时确认客户安装版本、设备兼容性及是否已经完成实测。

| 客户常见问题 | 统一答复 |
| --- | --- |
| 所有密钥都必须绑合同吗？ | 支持合同关联与无合同申请。在线后端强制规则取决于部署配置，离线开钥目前为可选关联；不要承诺所有场景无条件强绑定。 |
| 合同到期或没回款会自动停用吗？ | 当前合同关联用于追溯和审批。软件授权按密钥自身有效期及状态执行，不能将合同关联解释成自动回款或履约控制。 |
| 限制的是传感器数量吗？ | 限制安装并授权使用软件的电脑数量，每把密钥独立计数；不是传感器或串口设备数量。 |
| 老软件、老密钥会自动获得设备限制吗？ | 需要支持该机制的新版客户端。旧普通密钥不自动改成限量；旧无限量离线码需要重新签发对应限制格式。限制密钥也不能承诺永久不用联网。 |
| 客户更换电脑怎么办？ | 联系管理员处理原电脑授权或增加名额，不要直接保证无限次自行换机。已经离线的电脑不会在服务器解绑瞬间收到通知。 |
| Agent 会自动给出准确算法吗？ | Agent 辅助训练和测试，效果取决于采集质量、标签、场景和独立验证。保存算法、启用算法和达到业务准确率是不同结果；不能直接承诺准确率、医疗结论或舒适度结论。 |
| Agent 是否包含免费模型额度？ | 客户通常配置自己的模型服务密钥，费用按对应服务账户计算；软件授权与模型调用费用分别确认。 |
| 新增公司系统后，旧密钥能直接使用吗？ | 密钥必须包含对应系统权限。固定范围旧密钥不会因新增系统自动扩权，开通前要核对；员工提交也不等于已经发布或推广。 |
| 以后所有更新都不用重装了吗？ | 兼容网页、受支持的系统配置和算法可独立更新；新的后台、原生库、协议能力或模型资源仍可能需要安装包升级。 |
| 数据是不是完全不上传？ | 采集原始记录默认保存在本机。使用 Agent 时，所选资料或计算摘要会发给模型服务；聊天同步与使用统计另有独立告知和开关，不能宣传为完全不联网。 |

## 发布和演示口径

- 仅对已发布并完成目标设备验收的能力使用“已支持”“可直接使用”。源码实现或内部合成测试不能替代客户交付验收。
- 客户首次需更新到包含本轮后台、授权及 Agent 能力的完整客户端，服务端也需配套部署；仅更新网页不能补齐全部能力。
- 普通密钥不限量和限制密钥的规则需要在报价、试用、续费时讲清；限定电脑数量不是对所有旧客户的默认收紧。
- 员工本机草稿、聊天、模型密钥和采集数据库不应作为公司系统交付内容；正式系统须经过审核发布。
