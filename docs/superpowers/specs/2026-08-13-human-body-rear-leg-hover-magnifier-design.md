# 人体全身优化后腿数字矩阵与悬停数据放大镜设计

## 目标

在“人体全身优化”的 3D 场景中完成两项调整：

1. 后腿视角的 2D 数字面板保持“左后腿 / 右后腿”标题及槽位不动，只交换标题下方读取的左右后腿矩阵。
2. 鼠标悬停人体模型时，以最近的物理传感点为中心显示同一区域的 `3×3` 局部数据，帮助核对模型热力与传感器数据的对应关系。

## 数据边界

- 原始 1024 路实时帧、历史回放帧和左侧压力统计保持不变。
- 3D Shader、点云和线网继续使用现有 1120 个物理点及其双线性采样关系。
- 后腿矩阵交换仅作用于 3D 场景右下角、随部位视角切换的 2D 数字面板；`numoriginal` 原始数据模式不在本次范围内。
- 不修改串口解析、数据库存储、CSV 下载、模型文件或点位档案。

## 后腿 2D 数字矩阵

当前数字面板让同一个 `part` 同时决定标题和数据，无法表达“标题不动但交换数据”。本次将数字视图配置拆成两个明确字段：

- `displayPartKey`：决定标题、槽位和尺寸。
- `dataPartKey`：决定实际读取哪一块索引矩阵。

后腿视图使用以下映射：

| 固定显示槽位 | 标题 | 数据来源 |
| --- | --- | --- |
| 左侧槽位 | 左后腿 | `backPantsRight` |
| 右侧槽位 | 右后腿 | `backPantsLeft` |

两块数据仍分别执行当前已经确认的 2D 上下方向规则，不增加左右翻转。其它身体区域的 `displayPartKey` 与 `dataPartKey` 相同，行为保持不变。

## 悬停放大镜的数据链路

采用以下链路：

```text
Canvas 鼠标位置
→ Three.js Raycaster 命中人体 Mesh
→ 获得世界坐标 intersection.point
→ 在 1120 个物理传感点中查找最近点
→ 限定相同 region + placementSide
→ 按中心点 row/col 读取相邻 3×3
→ 使用各点现有 sample 权重从原始 1024 路帧计算数值
```

选择世界坐标最近点而不是 UV 反查，是因为当前优化渲染器的 Shader、点云和线网均使用同一组物理坐标，旧 UV atlas 不是该 Shader 的数据入口。这样放大镜与模型表面压力使用同一映射来源。

### 数值规则

- 每格使用该物理点的 `sample` 对原始帧进行双线性加权求和。
- 数字保持原始压力数据量纲；Shader 内部用于着色的 `×10` 强度放大不进入数字显示。
- `NaN`、缺失值或无效值按 `0` 处理。
- 3×3 固定按左上到右下排列，中心格高亮。
- 区域边缘不存在的相邻格显示 `—`，不得跨到另一条腿、另一只手臂或相邻部位。

### 命中限制

- 最近物理点与模型命中点的距离超过 `0.25` 时不显示面板，避免头、手、脚等无传感器覆盖区域误报。
- Raycaster 只检测人体 Mesh，不检测隐藏或可见的点云、线网。
- 五种渲染模式只切换材质或辅助对象，因此共用同一套 Mesh 拾取逻辑。

## 交互与布局

- 指针在有效传感区域稳定悬停约 `150ms` 后显示。
- 面板距离指针约 `18px`，并根据视口边缘自动切换方向和限制位置。
- 为减少视觉抖动，只在最近传感点发生变化时移动面板；原始帧更新时，面板原位刷新 3×3 数值。
- 面板使用紧凑半透明样式，展示区域名称、中心行列及 3×3 数据；面板本身设置 `pointer-events: none`，不拦截模型操作。
- 开始拖动或旋转模型时立即隐藏；拖动结束后需要重新稳定悬停才显示。
- 有效悬停期间暂停默认自动旋转，离开模型后恢复进入悬停前的自动旋转状态，避免模型从静止指针下移动导致数据指向失真。
- 离开 Canvas、命中无数据区域或组件卸载时取消定时器、隐藏面板并清理事件监听。

## 代码边界

- 后腿显示槽位与数据源关系提取为可独立测试的纯配置/纯函数。
- 最近点查找、距离阈值、3×3 邻域构造和加权值计算提取到独立纯函数模块。
- `HumanBodyOptimized.jsx` 只负责 Raycaster 事件、悬停生命周期和浮层渲染，不复制方向或传感器采样规则。
- 实时数据继续保存在 ref 中，悬停面板通过小范围更新刷新，避免每帧触发整个 Three.js 组件重渲染。

## 错误与降级

- 模型或点位档案尚未加载完成时不启用悬停。
- Raycaster 无命中、最近点超阈值或找不到有效区域时直接隐藏，不弹错误提示。
- 某个邻域点缺失时只显示 `—`，其它格继续工作。
- 放大镜异常不得阻断现有热力图、OrbitControls 或实时帧更新。

## 测试与验收

### Vitest

- 验证后腿标题/槽位不变，左右数据源交叉读取。
- 验证其它视角仍读取自身数据源。
- 验证最近点选择、稳定的同距处理和 `0.25` 距离阈值。
- 验证 3×3 中心、固定顺序、边界补空以及 `region + placementSide` 隔离。
- 验证每格加权值与现有 Shader 采样的原始值部分一致，但不包含着色专用 `×10`。
- 验证空帧、非数字数据和缺失邻域不会抛错。

### 浏览器 WebGL 验收

- 胸、背、左右臂、前后腿均能显示正确的 3×3；头、手、脚不误显示。
- 热力、水晶、线网、点云、叠加五种模式均可悬停。
- 面板在四个屏幕边缘不会出界，且不会遮挡或阻断拖动、缩放。
- 拖动时隐藏，重新悬停后恢复；自动旋转状态能正确暂停和恢复。
- 鼠标静止时，连续实时帧仍会刷新面板数值。
- 切换视角、展示模式或卸载组件后没有重复监听和残留浮层。
