# sqliteOpti 合并回退恢复设计

## 背景

`sqliteOpti` 在 `b56a854` 合并 `feature/离线密钥功能增加/260616/sqt` 时，以功能分支版本解决了多个冲突文件。新的在线/离线授权体系被正确引入，但 `deb42c3` 之前已经存在的若干展示与采集功能也被覆盖，包括小床监测12B压强标定、12B实时矩阵设置、SQLite批量写入、部分历史回放元数据、CSV UTF-8 BOM，以及 `matCol` 小床褥采集的显示与导出方向处理。

本次恢复不回退整个合并提交，也不恢复旧授权实现。目标是在当前 `sqliteOpti` 代码上保留 `licenseManager`、`sensorTypeStore`、在线/离线密钥校验、防时间回拨和新入口页面，同时逐项恢复被覆盖的业务能力。

## 目标

1. 恢复 `smallBed12B` 从清零后 ADC 到 kPa 的统一标定。
2. 保证实时显示、左侧统计、采集入库、历史回放和 CSV 下载使用一致的压强矩阵。
3. 恢复 `smallBed12B` 的 32×32、16×16实时显示及16×16采样点设置。
4. 恢复高频采集的 SQLite 批量写入与停止采集时的可靠刷新。
5. 恢复 CSV UTF-8 BOM、采集标签信息及 `matCol` 的视觉方向转换。
6. 恢复历史回放的时间数组、矩阵尺寸、方向和单位元数据。
7. 保留 `b56a854` 引入的全部授权和传感器类型管理行为。

## 非目标

- 不整体还原 `deb42c3` 的 `server.js`、`Home.jsx` 或授权页面。
- 不恢复旧的 `nowDate/endDate` 授权判断、旧在线时间服务器或桌面端发证功能。
- 不改变12B串口协议、1500000波特率、1024个 `uint16LE` 点和现有 `jqbed` 线序。
- 不修改数据库表结构。
- 不改变压强标定文件中的 V2.7.54 参数和公式。
- 不重构无关传感器的数据链路。

## 方案选择

### 采用：在当前代码上分模块恢复

将恢复逻辑拆成可独立测试的后端纯函数/小模块，并在现有 `server.js` 入口处调用。前端只恢复12B显示配置、历史时间数据和 `matCol` 注册，不替换当前授权页面与 WebSocket 授权状态处理。

优点：授权系统保持不变；恢复范围可审查；每条数据链可单独测试；不会把旧版 `server.js` 的其他行为整体带回。

### 未采用：只恢复压强公式

只解决实时画面的数值，但采集、回放、CSV、16×16模式和旧数据兼容仍不一致，因此不满足统一数据链目标。

### 未采用：整体恢复冲突前文件

会同时撤销在线/离线授权、动态传感器列表、入口页面和静态资源安全修复，冲突风险过高。

## 架构与职责

### 1. 12B压强数据模块

新增聚焦模块封装以下职责，并复用 `util/pressureCalibration_V2.7.54.js`：

- 将输入值规整为有限非负数。
- 只用大于标定阈值30的点计算 `ADC_avg`。
- 调用 `estimatePointPressure(ADC_avg, ADC_point)` 计算每点 kPa，并统一保留1位小数。
- 识别带 `pressureUnit: "kPa"`、`dataUnit: "kPa"` 或 `unit: "kPa"` 的历史帧，避免重复标定。
- 构建32×32或16×16实时展示帧，并保留 `matrixWidth`、`matrixHeight`、`sourceMatrixWidth`、`sourceMatrixHeight`、`matrixOrientation`、`matrixDownsample` 和 `pressureUnit`。

实时数据流：

```text
2048字节串口帧
  → 1024个uint16LE ADC
  → jqbed线序
  → 清零帧相减并钳制为非负
  → V2.7.54逐点kPa标定
  → 可选32×32/16×16展示采样
  → WebSocket / 左侧统计 / 采集
```

左侧 Pressure Data 与 Pressure Area 必须取协议解析和线序归一化后的同一份压强矩阵，不使用3D插值、高斯或渲染后的数据。

### 2. 12B历史与采集兼容

新采集帧以对象形式存储矩阵及单位元数据，至少包含 `sitData`、`pressureData`、矩阵尺寸和 `pressureUnit: "kPa"`。回放时：

- 有 kPa 单位标记：只规整和四舍五入，不再次套公式。
- 无单位标记的旧数组/旧对象：视为 ADC，在回放入口标定一次。
- 16×16历史帧保持16×16，不强制扩展为32×32；清零帧与回放首帧携带匹配的尺寸。
- CSV与曲线统计复用同一个历史归一化入口。

### 3. 前端12B显示设置

恢复 `Home.jsx` 中的12B显示状态与 WebSocket 配置传递：

- 实时矩阵模式只允许 `32x32` 或 `16x16`。
- 采样点使用现有 `topLeft` 等配置值，无效值回退为 `topLeft`。
- 设置写入 `localStorage`，重启后恢复。
- 切换到 `smallBed12B`、切换实时/回放或设置变化时，向后端发送 `smallBed12BDisplayOptions`。
- 收到帧的 `matrixWidth/matrixHeight` 后更新原始数字视图尺寸。
- 12B默认使用 kPa 色阶：默认颜色上限25，可调最大30，并恢复相应平滑、过滤默认值。

### 4. SQLite批量写入

恢复每个数据库连接独立的写入队列：

- 默认累计200行或等待250ms后刷新。
- `better-sqlite3` 可用时使用事务和预编译语句。
- 兼容回调式 SQLite 时逐行调用现有 `db.run()`。
- 用户停止采集、存储空间不足、数据库错误及服务关闭前刷新剩余队列。
- 写入失败继续走现有采集停止与前端错误广播，不吞掉异常。

该模块不改变写入数据结构，只替换逐帧立即 `db.run()` 的调度方式。

### 5. CSV与 `matCol`

- 所有文本 CSV 在文件开头写入 UTF-8 BOM，保证 Excel 中文兼容。
- 恢复采集名称解析出的 `label` 与 `labelText`。
- `matCol` 的10×16存储矩阵按既有规则转换为视觉16×10方向后导出。
- 恢复 `matCol` 的系统名称、授权模块选项、3D/原始数据模式和数字矩阵尺寸。
- 12B CSV 使用历史归一化后的 kPa 矩阵，压强总值不再套其他床垫的 `totalToN` 公式。
- 使用矩阵的 `matrixOrientation` 判断是否已转置，避免实时、回放或CSV重复转置。

### 6. 历史回放时间元数据

后端恢复 `historyTimeArr`，前端保存并传给曲线/回放组件。12B的零帧和首帧同时携带矩阵尺寸、方向和单位；其他传感器继续保持当前回放行为。

## 授权边界

所有串口解析、采集、历史操作和WebSocket数据发送继续以 `licenseManager.isLicenseValid()` 为入口条件。以下内容不得恢复：

- `nowDate < endDate`
- 旧 `sensor.bodyta.com` 时间校验
- 旧 `persistLicenseKey()` 授权写入流程
- 静态硬编码授权范围替代 `sensorTypeStore`

若恢复代码与授权代码位于同一冲突区域，采用“保留当前授权分支，再嵌入业务调用”的方式处理。

## 错误与边界处理

- 空帧或没有大于30的有效点：输出等长全零矩阵。
- `NaN`、无穷值、字符串及负数：规整为0或有限非负数，不污染平均值。
- 历史对象缺少尺寸：根据数据长度推断，无法推断时回退32×32。
- 16×16配置无效：回退32×32；采样位置无效：回退 `topLeft`。
- 数据库批量写入失败：停止采集、刷新可安全提交的队列并广播错误。
- CSV流写入失败：关闭流并沿用当前下载失败回包。

## 测试策略

### 后端自动化测试

使用 Node 内置测试运行器测试独立模块，不依赖启动 Electron：

- 12B公式阈值、平均值、逐点结果及1位小数。
- 全零、非法值和无有效点。
- 已标记kPa历史帧不重复标定，旧ADC历史帧只标定一次。
- 32×32/16×16帧尺寸、方向、单位与采样位置。
- 批量队列200行触发、250ms触发、停止时刷新及错误传播。
- CSV BOM、标签解析和 `matCol` 方向。

### 前端自动化测试

使用 Vitest 测试12B配置的归一化、缓存恢复、矩阵尺寸和WebSocket payload纯函数；现有前端测试保持通过。

### 集成验证

- `node --check server.js`。
- 后端新增测试全部通过。
- 前端专项 Vitest 全部通过。
- `npm --prefix client run build` 成功。
- 用模拟1024点12B帧核对实时、采集、回放和CSV的同一点kPa值一致。
- 核对在线/离线授权、锁定状态和动态传感器列表没有回退。

## 验收标准

1. `smallBed12B` 实时帧在后端完成一次且仅一次 V2.7.54 kPa标定。
2. 实时、左侧统计、采集、回放和CSV对同一帧给出一致的1位小数kPa值。
3. 新kPa历史数据不重复转换，旧ADC历史数据自动兼容。
4. 32×32和16×16显示均可切换、缓存并正确回放。
5. 停止采集后队列无遗留数据，数据库错误仍能通知前端。
6. 中文CSV带UTF-8 BOM，`matCol` 导出方向和16×10数字显示正确。
7. 当前在线/离线授权、防回拨锁定、重新验证和动态传感器类型功能保持不变。
8. 自动化测试、语法检查和前端构建通过，架构文档与实现一致。
