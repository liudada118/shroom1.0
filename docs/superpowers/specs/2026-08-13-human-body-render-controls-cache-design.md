# 人体全身优化渲染设置精简、折叠与缓存设计

## 目标

精简“人体全身优化”的渲染设置，只向用户展示热力和水晶两种模式；修复模型颜色在这两种模式下无效的问题；将设置面板改为可折叠；缓存用户修改的渲染设置；并让自动旋转/暂停只在全身视角生效。

## 渲染模式与面板

- 模式按钮只显示“热力”和“水晶”。
- 线网、点云、叠加按钮以及“线条 / 点云”颜色设置不再展示。
- 底层线网、点云资源和内部模式分支本次不删除，避免影响点位调试能力和既有加载/释放逻辑；正常用户入口无法再切换到这些模式。
- 设置面板使用一行标题栏和折叠按钮。展开时显示完整设置，折叠时只保留标题栏；折叠状态进入缓存。

## 扩散半径

- 扩散半径范围固定为 `0.05–0.13`，步进为 `0.01`。
- 没有有效缓存时默认值为 `0.13`。
- 缓存值、父组件 `renderOptions.size`、imperative `changeColor({ size })` 和用户滑块修改都经过同一个钳制函数，任何大于 `0.13` 的旧值都收敛到 `0.13`，任何小于 `0.05` 的值都收敛到 `0.05`。
- 有有效组件缓存时，缓存半径优先于 `Home` 传入的旧默认 `size=31`，避免组件挂载后又回到 `0.31`。外部后续明确修改 `size` 时仍通过同一入口更新并保存。

## 模型颜色修复

- 当前模型颜色只更新线网/点云使用的 `MeshPhongMaterial`，热力和水晶使用的 Shader 没有读取它，因此用户看不到变化。
- Shader 新增 `uModelColor`：
  - 热力模式无压力区域直接使用用户模型颜色；有压力区域仍使用所选热力色谱。
  - 水晶模式以用户模型颜色作为晶体基础色，再叠加压力色和 Fresnel 高光。
- 修改模型色时同时更新所有 Shader material 的 `uModelColor`；隐藏的 ghost material 继续同步更新，保持内部调试模式一致。

## 缓存

使用独立、版本化的 localStorage 单对象缓存，不复用 `Home.valueConfig`，避免与其他展示系统或通用最大值/过滤值配置互相覆盖。

缓存字段：

- `version`
- `mode`：只接受 `heatmap` / `crystal`
- `radius`
- `intensity`
- `opacity`
- `colorScheme`
- `bgColor`
- `modelColor`
- `settingsCollapsed`
- `overviewAutoRotate`

读取时逐字段校验并与默认值合并。JSON 损坏、版本不兼容、颜色格式错误或数值越界时，仅对应字段回退默认值，不阻止模型渲染。每次用户修改后写回整个规范化对象；缓存写入失败只忽略持久化，不影响当前会话。

不缓存当前部位视角：组件重新进入时仍从全身视角开始，但恢复全身上次保存的旋转/暂停状态。

## 全身自动旋转与部位视角

- 只有 `overview`（全身）视角显示“自动旋转 / 暂停”切换按钮。
- `overviewAutoRotate` 是用户偏好并进入缓存：`true` 表示全身自动旋转，`false` 表示全身暂停。
- 切换到胸、背、左右臂、前腿或后腿时，视角飞行并强制停止旋转；部位视角不显示旋转按钮。
- 返回全身时，视角飞行结束后恢复缓存中的 `overviewAutoRotate`。若缓存为暂停，则保持暂停。
- “重置视角”等同返回全身并恢复缓存状态，不再无条件启用旋转。
- 鼠标悬停、OrbitControls 拖动和视角飞行属于临时暂停：结束后只在当前仍为全身且用户偏好为自动旋转时恢复；部位视角或用户偏好暂停时不得恢复。
- 清理时取消悬停、视角飞行和恢复定时器，避免卸载后修改已释放的 controls。

## 数据与范围边界

- 不修改人体 1024 路原始数据、传感器点位 JSON、区域映射、2D 数字、悬停 3×3 数据、统计、回放、CSV 或后端。
- `max` 和 `filter` 仍由 `Home` 的 `renderOptions` 控制，不放入此组件外观缓存。
- 背景色、热力强度、水晶透明度和色谱行为保持现有渲染语义，只增加规范化缓存。

## 验收

1. 面板只显示热力、水晶，且可以折叠/展开；刷新或重新进入系统后恢复折叠状态。
2. 半径滑块范围为 `0.05–0.13`，首次默认 `0.13`；旧 `size=31` 不会把它恢复到 `0.31`。
3. 热力和水晶模式修改模型色后，无压力基础色立即可见变化。
4. 模式、半径、强度、透明度、色谱、背景色、模型色、折叠状态和全身旋转偏好在重新挂载后恢复。
5. 全身可切换自动旋转/暂停；部位视角始终暂停；返回全身和重置视角恢复缓存偏好。
6. 悬停和拖动时临时暂停，结束后不会违反当前视角和用户偏好恢复旋转。
7. 人体方向、数字、悬停数据专项测试通过，前端生产构建通过，并更新 `ARCHITECTURE.md` 与生产构建资源。
