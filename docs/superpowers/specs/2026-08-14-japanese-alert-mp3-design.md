# 日文生命体征告警 MP3 资源设计

**日期：** 2026-08-14
**目标分支：** `Revise`

## 目标

为生命体征固定告警生成三条可随 Electron 应用离线播放的日文 MP3，避免运行时依赖操作系统日文语音包或云端 TTS。此轮只增加音频资源，不修改现有 Web Speech 播报逻辑。

## 输出资源

输出目录为 `client/public/audio/alerts/ja/`：

| 文件 | 播报文本 | 使用场景 |
| :--- | :--- | :--- |
| `left-bed.mp3` | `離床しました` | 已离床 |
| `edge-seat.mp3` | `端座位` | 已坐起、坠床风险共用 |
| `emergency.mp3` | `SOS緊急通報` | SOS 紧急求助 |

## 生成方案

- 使用 Microsoft 在线日文女声 `ja-JP-NanamiNeural` 一次性生成。
- 生成工具在系统临时目录的独立 Python 虚拟环境中运行，不写入项目 `package.json`、`requirements.txt` 或应用运行依赖。
- 生成阶段需要联网；生成后的应用资源离线可播放，不需要 Azure API Key，也不需要 Windows/macOS 日文语音包。
- 语速轻微降低以保证医疗告警清晰度，音调使用声音默认值。
- 生成工具只用于资产制作，不在 Electron 运行时调用，避免产品运行依赖非正式在线接口。

## 验证

- 三个文件均存在且大小大于零。
- 文件头符合 MP3/ID3 格式，能够由本地音频解码器读取。
- 输出目录只包含预期三条日文告警文件。
- 将三个文件作为本地链接提供给用户试听；不把试听结果伪装为自动语义校验。

## 非目标

- 不修改 `Home.jsx` 或 `speechSynthesis.js` 的运行时播报路径。
- 不生成中文或英文语音。
- 不安装系统日文语音包。
- 不接入 Azure Speech 账号、密钥或计费服务。

## 文档与提交

生成完成后增量更新 `ARCHITECTURE.md`，记录固定日文告警资源的位置、文本、声音和离线边界，并将三条 MP3、文档和必要的生成验证记录提交到 `Revise`。
