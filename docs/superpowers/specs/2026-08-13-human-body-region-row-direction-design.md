# 人体全身优化区域上下方向修正设计

## 目标

修正人体全身优化中后背（`back`）和右手臂（`rightArm`）的压力数据上下方向，使 3D Shader 热力映射与场景内 2D 数字面板保持一致。其它身体区域、点位三维坐标、原始 1024 路数据、左侧统计、回放和 CSV 数据不变。

## 现状与根因

- 3D 渲染根据 `HUMAN_BODY_SENSOR_PARTS` 中每个区域的原始索引矩阵，对 v7 模型点位的 `row/col` 做双线性采样。
- 采样默认将模型 `row 1` 映射到原始矩阵第 1 行，没有区域级行方向配置。
- 后背和右手臂的实际安装方向与该默认方向相反，造成压力在模型上上下倒置。
- 2D 数字面板有独立翻转集合，容易与 3D 映射产生方向漂移。

## 设计

在 `HumanBodyOptimized.jsx` 中增加单一的区域方向配置：

```js
const PART_ORIENTATION = {
  back: { flipRow: true },
  rightArm: { flipRow: true },
};
```

3D 的 `buildSample()` 在计算双线性采样位置前读取该配置：

```text
正常：sourceRow = normalizedRow × (sourceHeight - 1)
翻转：sourceRow = (1 - normalizedRow) × (sourceHeight - 1)
```

2D 数字面板调用同一配置，对对应区域执行行数组反转。现有横向显示规则继续保留；后裤现有纵向显示规则也继续保留。方向配置只作用于区域数据读取，不修改 `sensor_canvas_positions.json` 中的三维坐标。

## 数据影响

- 后背：原始 6×10 的第 6 行映射到模型 12×10 的第 1 行，第 1 行映射到模型最后一行。
- 右手臂：原始 6×7 的第 6 行映射到模型 6×15 的第 1 行，第 1 行映射到模型最后一行。
- 其它区域保持现有映射。
- 左侧 Pressure Data / Pressure Area 继续直接统计原始 1024 路帧。
- 实时与回放仍通过同一个 `sitData()` 入口，因此共享修正后的显示方向。

## 验证

1. 添加方向映射单元测试，先证明当前后背和右手臂首尾行方向不符合预期。
2. 实现共享方向配置后验证测试通过。
3. 验证前胸、左手臂和裤区等未配置区域的映射保持不变。
4. 执行生产构建，并检查 `git diff --check`。
