# 后端兼容资料

这个目录只保存迁移基线和仍被历史数据路径使用的辅助函数，不是旧模块路径的兼容转发层。

| 文件 | 用途 |
| --- | --- |
| `openWeb.js` | 旧线序、映射和算法的大文件基线，用于迁移对比；新增运行时不应直接依赖它 |
| `legacyDataUtils.js` | 现有历史/旧数据链路仍需的窄范围辅助函数 |

原后端旧路径 CommonJS 转发层已经移除。新增业务代码不要从本目录获取通用能力；协议、串口、采集、存储和处理应使用 `@shroom/backend/...`，应用装配应使用 `backend/kernel/`。

清理本目录中的任何文件前，必须先确认真实历史数据库和回放数据不再依赖，并按高风险兼容性变更进行人工评审。
